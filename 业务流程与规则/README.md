# 业务流程与规则

个人系统的运行循环是：收件与保存 -> 来源定位 -> 观点或模型 -> 问题地图 -> 决策 -> 行动 -> 观察 -> 复盘。具体内容仍以 `知识库/` 中的条目为准。

| 阶段 | 主入口 |
|---|---|
| 收件与来源 | `知识库/01-收件箱/`、`知识库/10-原始资料/` |
| 当前画像 | `知识库/15-个人档案/` |
| 观点与研究 | `知识库/20-观点笔记/`、`知识库/25-投资研究/`、`知识库/30-模型笔记/` |
| 问题与冲突 | `知识库/40-问题地图/`、`知识库/80-审核与权重/` |
| 决策与行动 | `知识库/50-决策记录/`、`知识库/60-行动项目/` |
| 结果与更新 | `知识库/70-复盘更新/` |

不要为了完成流程而强行把每份材料变成行动；只有与真实问题相关且有可观察结果时才升级。
