[P0114] 2. **四大隐蔽盲点与危险**：

[P0115] - **盲点1（宏观叙事向个股映射的确定性幻觉）**：认同美股并联融资与“纳指七姐妹”脑力垄断，不代表在任何估值（如35x-45x PE）下买入都能获得高回报。Mauboussin《The Base Rate Book》实证表明高ROIC与高增长存在显著的5-10年均值回归。

[P0116] - **盲点2（个股集中度与正偏态陷阱）**：Bessembinder (2018, JFE) 对1926-2016年美股25,300只股票的全样本研究证明，58%的个股终身收益跑输一个月期国库券，全部净财富创造仅来自4%的顶尖公司。在能力圈未经完整周期验证前，宽基指数必须作为压舱石。

[P0117] - **盲点3（微观田野调查的小样本偏差）**：旗舰店与核心商圈的高客流观察容易引发“努力引致的确认偏误”，必须通过财报全量存货周转、同店增速（SSSG）与分部利润率进行交叉证伪。

[P0118] - **危险4（极简饮食对人力资本母机的潜在耗散）**：每日20元饮食需严防优质蛋白与微量营养素不足，应将营养与体检划入“生产性资本维持性CapEx”。

[P0120] - **30岁前（3年）100万RMB**：**高可行性（≥80%）**。初始12万 + 每年定投21万，仅靠本金即可达75万；在8%–10%年化基准收益下可达86万–90万+，结合薪资微增或副业可稳健达成。严禁为凑整而在最后一年加杠杆。

[P0121] - **10–15年（37–42岁）5,000万RMB**：**仅靠21万/年储蓄+二级市场常规投资属极小概率事件**。根据 Dimson, Marsh & Staunton《UBS Global Investment Returns Yearbook 2025/2026》，美股125年年化名义回报率为9.7%（实际回报率约6.5%）。即便按年均储蓄35万+15%年化复利（顶级价值投资分位），15年后约为1,763万RMB（已完全实现高安全边际财务自由）；若强求12年5,000万则需高达41.5%的年化收益率，必然诱导杠杆毁灭。建议将里程碑修正为：30岁100万 → 35-37岁500万 → 42-45岁1,500万-2,000万；向5,000万跃迁必须依靠“铲子端（工业AI标准化产品/副业现金流）”的非线性扩张。
