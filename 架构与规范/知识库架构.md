# 可扩展的个人知识库架构

本库参考“宏远知识库”的入口、规范、模板、流程、问题、证据和原始资料分层，同时保留个人库已有的编号目录。

## 运行形态

单人、本地、文件优先。Markdown 是人工阅读和维护的正文；原始文件是证据，不在整理文档中覆盖修改。Git 可用于文本历史，不能替代独立备份。

```text
原始资料
  -> 来源索引与定位
  -> 观点 / 模型
  -> 问题地图
  -> 决策
  -> 行动与观察
  -> 复盘与规则更新
```

## 目录约定

```text
README.md / 项目概览.md / 知识库建设方案.md
架构与规范/
模板/
业务流程与规则/
需求与测试/
问题复核/
证据索引/
原始资料/
知识库/                  # 现有个人知识条目主库
_research/               # 外部研究和核验工作区
```

`知识库/` 内的 `01-收件箱`、`10-原始资料`、`15-个人档案`、`20-观点笔记`、`25-投资研究`、`30-模型笔记`、`40-问题地图`、`50-决策记录`、`60-行动项目`、`70-复盘更新`、`80-审核与权重`、`90-模板`、`95-合成演示`、`99-归档` 保持原编号，不因迁移改名。

## 权威位置

- 原始文件：`知识库/10-原始资料/` 及其来源说明。
- 当前个人知识：`知识库/15-*` 至 `知识库/80-*` 的主题文档和审核表。
- 模板：顶层 `模板/` 便于发现；旧条目中的 `知识库/90-模板/` 作为迁移快照保留。
- 外部证据：`_research/`，通过 `证据索引/` 和主题文档引用。

同一结论只保留一个权威正文；导航页只负责链接，不复制长篇内容。
