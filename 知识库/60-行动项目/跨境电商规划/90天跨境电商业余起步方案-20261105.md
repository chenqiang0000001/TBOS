# 90天跨境电商业余起步方案

制定日期：2026-11-05，北京时间。若2026-11-06开始，90天截至2027-02-03。

本方案依据当前个人资料和本次补充制定。你已明确：**跨境电商、业余起步、从零开始，首轮总预算5000元，每周15小时。** 下文的商品、支出分配、止损线和检查条件是建议，尚不是你已作出的经营承诺。没有预填任何销售成果。

**我的判断：值得做一次有边界的跨境经营试验。先验证“一个平台、一个目的国、一个具体需求、1—2款小库存商品”，再决定是否追加。首轮优先核实eBay个人卖家路径及国内自发货的可行性。** 亚马逊FBA留到资金和商品证据足够时重新测算。

## 先选经营方式，再核定平台与市场

| 路线 | 与当前条件的匹配 | 本轮安排 |
|---|---|---|
| eBay、小库存、国内自发货 | 可控制首次库存；仍须解决本人开户资格、收款、销售额度、可追踪物流和退货成本 | 第一候选，先过门槛再上线 |
| Amazon FBA | 海外备货、头程、仓储、销售费用和售后共同占用资金；补货与回款有时间差 | 本轮不配置海外库存，留作后续比较 |
| Amazon自发货 | 可减少海外备货，但开户、销售费用、时效和售后仍需逐项核算 | eBay路径不成立时可以复核，不能自动视为更便宜 |
| TikTok Shop内容经营 | 需要核实具体市场准入，并承担持续素材、流量与履约任务；当前没有账号或内容资产 | 暂不作为首轮主线 |
| Shopify独立站 | 还需解决获客、支付与信任；目前没有流量基础 | 暂缓 |
| 全托管 | 托管能减少部分运营任务，仍需供货、质量和价格能力 | 当前无货源，暂缓 |

这张表是对你当前资源的判断，不是平台盈利能力排名。

**第一周只做开户路径核验，不急于购买服务或注册公司。** eBay中国官方入驻页写明允许个人卖家入驻；同页企业招商问答另外列有公司年限等要求。企业招商通道和个人卖家路径应分别核对，不能将其中一项要求直接外推到所有账户。[官方入驻页](https://damai.ebay.cn/)

核验时使用自己的真实居住地与身份，确认适用账户类型、身份审核、收款支持、销售额度、资金暂扣、退货地址和经营登记义务。平台允许注册个人账户，不等于持续经营可以免除属地登记、税务等义务。涉及主体形式或持续费用时，先向平台和当地主管部门核实；开户成功也不等于商品已经具备盈利条件。

**目的国先比较美国和澳大利亚，第二周只留下一个。** 选择它们是为了将研究范围限制在英语市场，不预判谁是“蓝海”。用同一商品、同一包裹尺寸重量取得两国的全程物流报价，并核对进口税费承担方式、平台代征项目、追踪和退件方案。选择你本人能够开店、商品可以销售、报价后仍有利润且能履约的一国；两国均不成立，就停止这一商品方案。

英语水平尚未提供。第一周做一次实用测试：读懂10条商品描述和10条差评，写出尺寸说明、物流延迟、退款沟通三类回复。可以借助翻译工具，但最终要能核对尺寸、材质、数量和承诺。将需要补充的词汇放进实际任务，不额外启动一套大而全的英语课程。

## 商品从你能检查清楚的需求切入

首轮仅研究两个场景，再留下一个：

| 候选场景 | 可研究的商品 | 必须找到的需求证据 |
|---|---|---|
| 桌面、工位线材与小物整理 | 非电气的标识、固定带、小收纳袋组合 | 用户具体在抱怨什么：尺寸不清、标签难辨、安装麻烦，还是组合缺项？你的样品能否改善其中一项？ |
| 手工工具和配件分类收纳 | 空收纳包、小型分隔收纳件 | 买家实际收纳什么、需要什么尺寸，现有商品哪里不匹配？避免凭自己的使用习惯代替海外需求 |

这些是研究候选，不是已经确认能卖的商品。通用收纳品可能竞争激烈；如果最终只能靠同款降价，就换需求，不为选好的名称继续投入。

初筛可暂用：包装后尽量不超过300克、最长边尽量不超过25厘米、结构简单、尺寸可说明、无需复杂安装。目标成交价暂看人民币等值150—300元，再由竞品和物流报价修正。以上是缩小研究范围的工作假设，不能作为市场价格或物流资费结论。

对零基础小预算，优先选择准入和售后负担较低的普通用品。带电、液体、食品、儿童用品或涉及品牌授权的商品，需要额外条件，本轮先不选。

你可以把测试方法用于样品：记录实测尺寸、包装重量、材质与气味、连接和固定效果、正常使用中的破损、说明是否容易误解，以及两次采购的一致性。只表达你实际检查过的结果。制造业接触经验是检查商品的起点，不意味着已经掌握消费者偏好或可以使用雇主、客户的资料。

## 用单笔贡献判断商品，再用经营账判断项目

先估计：

**单笔贡献＝成交收入－采购－包装－全程物流－平台与收款费用－获客费用－卖家承担的税费－售后预计净损失－汇兑及提现成本。**

以下全部为人民币等值的计算示例，**不是商品报价、平台费率或收益预测**：

| 项目 | 示例金额 |
|---|---:|
| 成交收入 | 180元 |
| 采购 | −25元 |
| 包装 | −3元 |
| 全程物流，不含下列税费 | −50元 |
| 平台与收款 | −27元 |
| 获客费用 | −12元 |
| 卖家实际承担的税费 | −8元 |
| 售后预计净损失 | −12元 |
| 汇兑与提现 | −3元 |
| **单笔贡献** | **40元，约22.2%** |

40元仍需覆盖固定成本和你的劳动。假如一次性固定成本为800元，仅覆盖它就需要20笔同样贡献的订单，尚未补偿工时。若物流增加15元、售后预留增加10元，贡献就只剩15元。

首轮可把“预计贡献至少30元且至少占收入20%，运费上升后仍为正”作为入围条件；这是本方案的筛选标准，不是行业通用合格线。两项均应满足，再比较销售可能性。

用真实资料替换示例时注意三个口径：

- 平台可能按含运费、税等不同计费基数收费，收款和跨境附加费也可能另计，不能只套一个佣金比例。
- 物流含税报价与单独税费不重复扣；平台代收代缴的买家税款，不自动全部算作卖家额外费用。
- 预测中使用售后预留；实际账按真实退款、损耗和残值结算，同一笔损失只计一次。

每周分别看经营利润与现金：收入到账多少，费用发生多少，库存和在途货占用多少，平台还有多少款未释放，未来还欠多少费用。利润表为正也可能暂时缺现金。多币种先保留原币，按真实结算记录统一口径，不借本轮试验判断汇率方向。

## 每周15小时怎样安排

工作日每天1小时，共5小时；周六5小时，周日5小时。营业后，每天先留15—20分钟处理消息和订单，计入这15小时，不额外叠加。

| 每周用途 | 时间 | 对应产出 |
|---|---:|---|
| 商品、客户与竞品研究 | 3小时 | 一个需求判断或被排除的商品理由 |
| 供应商、样品、物流或实际履约 | 4小时 | 一份报价、验收记录或完成的订单流程 |
| 刊登、图片、英文说明和客户沟通 | 4小时 | 可使用的商品页面与准确回复 |
| 当前任务所需的官方规则和英语学习 | 2小时 | 解决当周具体问题 |
| 记账和周复盘 | 2小时 | 更新后的成本、现金与下周决定 |

不同阶段可以调配，但总量先不超过15小时。若主业进入忙期，减少新上架和新备货，优先履行已有订单。连续两周明显挤占睡眠或主业交付，就缩小试验。

知识库只增加必要记录：商品假设、成本和订单账、每周决定。使用配套[首轮验证工作台](首轮验证工作台.md)。不另建复杂系统；每周先留下一个可检查的经营成果。

## 90天后怎样决定

**继续同规模：** 有真实订单、预计售后成本已被观察部分支持，单笔贡献为正，供应稳定，日常工时可接受，但样本还小。

**修改一次：** 问题能定位到尺寸说明、组合、物流或价格等一项，并且修正后仍有利润空间。一次改一个主要变量，保留改动前后的记录。

**停止该方案：** 准入或主体成本不适合本轮预算；物流和税费后无合理利润；样品不稳定；买家没有理由选择；达到亏损控制线；或你不愿长期承担日常售后。停止要完成既有订单和账务收尾。

**考虑下一轮小幅扩大：** 建议至少观察两个分开的补货批次、合计20笔以上真实到货订单，并等待足够的售后观察期。即便达到，也只说明可以考虑再试一轮，不证明统计稳定或可以大规模投放。扩大前单独批准资金，重算一个补货周期的采购、运输、广告、退款和回款延迟。

未来6—12个月，先把一个需求和一套履约流程做稳；只有出现明确需求证据才增加款式。再按真实利润比较继续自发货、改FBA或其他仓配。转全职要另外评估：至少连续6个月的可持续经营净收益，能否覆盖税后工资、替代吃住福利、社保税务及家庭责任，并保有充足生活和经营缓冲。当前约2000元消费不能直接作为离职后的生活成本。

你可以保留“MES职业积累＋跨境试验＋长期投资学习”，但近期新增经营项目只保留这一个。跨境带来的供应商协调、成本和交付记录，也可能反过来帮助项目管理能力积累；是否发生这种帮助，以实际成果为准。

## 第一周完成什么

1. 将“5000元、15小时、0基础”写入工作台，列出固定可用时段。
2. 通过eBay官方入口核实本人适用的开户、收款、额度与主体条件，保存带日期的说明；条件不清楚时先不支付代办或注册费用。
3. 两个商品场景各初看6个商品，标出买家、用途、价格、尺寸与差评。
4. 完成英语实用测试，并把3个入围商品需要的供应商、包裹与物流问题列出来。
5. 周末复盘：留下3个商品继续报价，或说明为何没有商品值得进入下一步。
