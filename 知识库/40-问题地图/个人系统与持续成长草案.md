# 个人系统与持续成长草案

状态：结构方案仍为建议。已明确“通用成长＋投资判断”，并接入2026-11-05本人确认的[当前状态与长期方向](../15-个人档案/00-当前状态与长期方向.md)；其他履历、财务口径、价值排序和建议采纳状态仍以审核结果为准。

## 1. 材料呈现的主线与尚不能确定的部分

六份材料反复围绕职业现金流、储蓄、长期投资、学习复盘、生活习惯和选择权展开。材料三更突出内容副业与个人表达，材料五更突出商业叙事和证据辨析，材料六则增加大量具体投资分析与配置建议。

这足以组织成一个共同框架，但不支持直接生成“当前完整画像”。尤其需要分开：个人经历与AI推断，某时点状态与当前状态，愿景与承诺，研究对象与持仓，计算情景与实际结果。对应来源和条目见[审核入口](../80-审核与权重/00-审核入口.md)。

## 2. 系统应围绕六个问题运行

| 问题 | 需要的数据 | 形成的产出 | 反馈方式 |
|---|---|---|---|
| 当前真实处境是什么 | 本人确认的职业、资金、时间与生活责任 | 带生效日期的状态快照 | 有变化时追加新版本 |
| 现在真正重视什么 | 本人认可的目标、原则与约束 | 一页系统章程 | 目标冲突或阶段变化时复查 |
| 哪个现实问题值得投入 | 备选问题、价值与机会成本 | 当前重点问题及信息缺口 | 检查它是否影响实际选择 |
| 依据是否足够 | 来源、主张、反证、适用范围 | 待判断的选项与模型 | 对照后续信息更新 |
| 下一步做什么 | 本人采纳的选择、投入上限和观察标准 | 决策与最小行动 | 留下真实交付和结果 |
| 哪条认识需要改变 | 事前记录、执行及实际观察 | 复盘与规则变更 | 回写观点、行动方法或目标 |

现阶段应先完成前两项的必要部分。历史数字未核准前，不计算财务自由进度、不把旧仓位方案写成当前配置，也不将任何AI自我评价设为固定身份。

## 3. 通用成长与投资判断共用同一反馈底座

### 通用成长入口

从职业能力、内容表达、学习方法、生活安排或关系问题中选择一个实际问题。将“我擅长什么”落到可展示的项目、作品、交付和复盘上，将“我想变好”落到可以检查的一次行动。

本人已确认的职业发展方向是从MES测试走向MES项目经理。职业问题地图据此连接现有测试经验与项目交付能力；宁波、杭州工作地偏好和美国移民长期规划作为已确认意向记录，具体路线与阶段行动另行决定。

材料中已有多种学习和自律目标。审核时可以保留、修改或删除，不必把最高时长、最多次数和最严格标准组合起来。用实际改变判断一个方法是否值得继续，允许休息和不以产出衡量的生活内容存在。

### 投资判断入口

先厘清资金用途与能力边界，再依次整理商业模式、财务质量、估值假设、反对证据和组合约束。企业事实、价格日期、模型参数和个人偏好分别保存。

材料六中已有的买入区间、配置比例和收益测算先保留在待验层；它们不会因为已经写得精确，就变成当前行动指令。个人确认某个愿望，也不会使外部行情、财报或税法自动核实。

两个入口都采用：

**问题 → 本人确认的状态与边界 → 有出处的认识 → 事前判断 → 实际行动 → 结果观察 → 修订。**

## 4. 候选反馈关系

以下是用于提问和记录的设计假设，不是已经观察到的个人规律。

- 职业与资金：可验证的职业成果可能改善现金流，现金流支持生活和长期项目；不能由高储蓄推导投资不会亏损。
- 学习与应用：自己的表述帮助暴露理解缺口，实际应用产生反馈，再修改笔记与方法；笔记数量不直接代表能力。
- 目标与负荷：多个高标准目标可能争夺时间与注意力；若维护和考核持续挤占行动，应减少并行项目或简化指标。
- AI与独立判断：AI提供整理和反方意见，由本人审核来源、解释与标签；确认后的认识仍允许被后续证据推翻。

## 5. 审核后的最小运行方式

1. 只将已确认且仍适用的必要信息写入“当前状态”；不确定项保留缺口。
2. 将本人认可的目标和原则写入[个人系统章程](../00-个人系统章程.md)。
3. 从本页选一个现实问题，用[决策记录](../90-模板/T04-决策记录.md)保存当时的认识。
4. 用[行动与观察](../90-模板/T05-行动与观察.md)记录下一步、投入与交付。
5. 条件满足时写[复盘](../90-模板/T06-复盘更新.md)，回连需要修订的条目 ID。

不需要等待123条全部通过才能开始，但某项决定依赖的关键前提应当先得到处理。当前没有代你确定副业发布计划、投资交易或长期生活安排。

## 6. 持续成长的记录单位

成长可以记录为：“原来如何理解 → 实际做了什么 → 观察到什么 → 为什么调整 → 下一次如何判断”。

保留曾经的误判、未执行的想法和被放弃的方案，但写明它们的性质。一个想法未被执行，不应变成成功或失败业绩；一次结果好坏，也不应直接变成对人格与全部能力的评价。
